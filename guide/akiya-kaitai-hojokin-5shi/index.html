空き家の解体補助金、5市の実例。交付決定前の契約・着工は対象外

更新日 2026-09-07執筆・監修 解体案内所事務局

空き家の解体に対する補助は市区町村ごとの制度で、名古屋市は工事費の3分の1・上限40万円（判定が125点以上なら3分の2・上限80万円）、札幌市は上限50万円（地域連携型は150万円）、北九州市は上限30万円、福島市は特定空家等で5分の4・上限150万円、新潟市は跡地活用で3分の1・上限50万円が案内されています。5市すべてに共通するのは、交付決定より前に契約または着工した工事は対象外になることです。もう一つの共通点は年度予算の先着で、福島市の特定空家等の枠はすでに受付を終了しています。順番は「自治体に確認 → 見積 → 申請 → 交付決定 → 契約・着工」です。

「空き家の解体に補助金は出ますか」。答えは市区町村によって違う、が正確です。ただ、制度がある自治体には共通するルールが2つあります。交付決定より前に契約・着工すると、補助は一切出ません。そして年度の予算内で先着（危険度の高い順、抽選のところもあります）。つまり順番は、自治体に確認してから見積を取り、申請して交付決定を受けてから契約・着工、です。この記事では、5つの市の実例と、共通するルール、申請から着工までの流れを整理します。

実際に出すのは市区町村、土台は国の制度

国土交通省の空き家対策総合支援事業は、市区町村が空家等対策計画に基づいて行う空き家の活用や除却の取組を、国が支援する制度です。除却工事の国費率は、空き家の所有者等が実施する場合で国が5分の2、市区町村が5分の2とされています（事業期間は平成28年度から令和7年度）。

つまり、解体の補助金は国が個人に直接出すものではなく、市区町村が制度を作り、そこに国が乗る形です。だから「解体の補助金はあるか」という問いには、家のある市区町村を見ないと答えが出せません。

5市の実例

上限額も対象も、市によってこれだけ違います。

名古屋市 老朽危険空家等除却費補助金 腐朽・破損が著しく、周辺に保安上の危険を及ぼしている家屋で、市の評価が75点以上の特定空家等 75点以上は工事費の3分の1（最大40万円）／125点以上は3分の2（最大80万円） 先着。予算額に達し次第終了
札幌市 危険空家等除却補助制度 原則として1年以上使用されていない建物等で、市の事前確認で危険性ありと判断されたもの 通常型は上限50万円／地域連携型は工事費の10分の9などで上限150万円 令和8年5月15日〜9月30日。予算に達し次第終了。予定数に達した日の申請は抽選

金額・条件・受付期間は年度ごとに変わります。上の表は制度を見比べるための材料で、申し込む前には必ず市のページと窓口で最新の内容を確かめてください。

5市すべてに共通する2つのルール

1つ目は、交付決定より前の契約・着工は対象外ということです。表現は市によって違いますが、内容は同じです。名古屋市は「補助金の交付決定前に着手した工事は対象外となります」、札幌市は「交付決定前に契約された工事は対象になりません」、北九州市は「『補助金交付決定通知書』を受領したのちに解体工事に着手することができます」、福島市は「交付決定前に解体の契約を行っていないこと」。着工だけでなく契約の時点でアウトになる市がある、というのが肝心なところです。良い業者が見つかって、その場で契約書に判を押した瞬間に補助が消える、ということが起こります。

2つ目は、年度予算と先着です。福島市の特定空家等の枠は、申請多数のためすでに受付を終了しています。北九州市は危険度の高いものから優先、札幌市は予定数に達した日の申請は抽選です。当社は、補助金は「あるかどうか」より「今年度まだ枠が残っているか」を先に確かめるものだと考えています。

申請から着工までの順番

  1. 家のある市区町村の空き家担当課に、制度の有無と対象を確認する。このとき今年度の受付期間と、枠が残っているかも聞く
  2. 明細つきの見積を取る（申請書に工事費の内訳を添える制度が多いため）
  3. 交付申請
  4. 交付決定通知を受け取る
  5. 契約・着工
  6. 工事完了の報告、補助金の請求

3と4の間には、市の現地確認や危険度の判定が入ることがあります。名古屋市は点数、北九州市は基礎の破断や屋根の剥落・ずれなどで判定します。ここに数週間から1か月以上かかることがあるので、「年内に更地にしたい」といった予定があるなら、逆算して早めに動いてください。

まとめ

  • 解体の補助は市区町村の制度。上限は30万〜150万円と幅があり、対象の条件もそれぞれ
  • 5市すべてで、交付決定より前の契約・着工は対象外。契約の時点でアウトになる市もある
  • 年度予算・先着。福島市の特定空家等の枠はすでに受付終了
  • 順番は「自治体に確認 → 見積 → 申請 → 交付決定 → 契約・着工」
  • 判定や現地確認に時間がかかるので、解体の予定日から逆算して動く

解体案内所でできること

当社は解体工事の施工をしません。ご相談をいただいたら、家のある市区町村に解体の補助金があるか、対象と受付の状況はどうかをお調べして返し、あわせて地域の登録業者から明細つきの見積を最大3社まで手配します。業者からあなたへ営業電話をかけることはなく、お断りのご連絡は解体案内所事務局が代わりに伝えます。

よくある質問

見積を取ってから申請しても間に合いますか

見積は先で構いません。対象外になるのは、交付決定より前に「契約」または「着工」をした工事です。札幌市と福島市は契約の時点でも対象外になると明記しているので、契約書に判を押す前に交付決定を受けてください。

どこの窓口に聞けばいいですか

家のある市区町村の空き家担当課です。住んでいる場所ではなく、建物のある自治体の制度が適用されます。聞くことは3つ。制度があるか、うちの家が対象か、今年度の枠がまだ残っているかです。

補助金が出る家と出ない家の違いは何ですか

老朽度や危険度の判定が入る制度が多く、名古屋市は点数（75点以上・125点以上）、北九州市は基礎の破断や屋根の剥落などで判定します。北九州市は昭和56年5月以前の建築という条件もあります。まだ住める状態の家は対象外になることが多いです。
