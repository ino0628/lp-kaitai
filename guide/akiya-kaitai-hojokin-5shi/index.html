空き家の解体補助金、5市の実例。交付決定前の契約・着工は対象外

2026年 最新版執筆・監修 解体案内所事務局

結論

空き家の解体に対する補助は市区町村ごとの制度で、名古屋市は工事費の3分の1・上限40万円（判定が125点以上なら3分の2・上限80万円）、札幌市は上限50万円（地域連携型の上限150万円は、令和8年度は令和9年度以降の交付申請を目指す案件の協議・相談を受け付ける枠）、北九州市は上限30万円、福島市は特定空家等で5分の4・上限150万円、新潟市は未接道地に建つ空き家の解体などで3分の1・上限50万円ですが令和8年度分は8月28日に受付を終了しました。5市すべてに共通するのは、交付決定より前に着工した工事は対象外になることです。札幌市と福島市は「契約」の時点でも対象外と明記しています。もう一つの共通点は年度予算の先着で、福島市の特定空家等の枠と新潟市はすでに受付を終了しています。順番は「自治体に確認 → 事前確認・判定 → 見積 → 申請 → 交付決定 → 契約・着工」です。

「空き家の解体に補助金は出ますか」。答えは市区町村によって違う、が正確です。ただ、制度がある自治体には共通するルールが2つあります。交付決定より前に着工すると、補助は一切出ません（札幌市と福島市は契約の時点で対象外）。そして年度の予算内で先着（危険度の高い順、抽選のところもあります）。つまり順番は、自治体に確認してから見積を取り、申請して交付決定を受けてから契約・着工、です。この記事では、5つの市の実例と、共通するルール、申請から着工までの流れを整理します。

実際に出すのは市区町村、土台は国の制度

国土交通省の空き家対策総合支援事業は、市区町村が空家等対策計画に基づいて行う空き家の活用や除却の取組を、国が支援する制度です。除却工事の国費率は、空き家の所有者等が実施する場合で国が5分の2、市区町村が5分の2とされています。事業期間は令和8年度から令和12年度、令和8年度の当初予算は59億円です（国土交通省住宅局「令和8年度 住宅局関係予算概要」）。

つまり、解体の補助金は国が個人に直接出すものではなく、市区町村が制度を作り、そこに国が乗る形です。だから「解体の補助金はあるか」という問いには、家のある市区町村を見ないと答えが出せません。

1つ目は、交付決定より前の着工は対象外ということです。表現は市によって違いますが、内容は同じです。名古屋市は「補助金の交付決定前に着手した工事は対象外となります」、札幌市は「交付決定前に契約された工事は対象になりません」、北九州市は「『補助金交付決定通知書』を受領したのちに解体工事に着手することができます」、福島市は「交付決定前に解体の契約を行っていないこと」。札幌市と福島市は、着工ではなく契約の時点でアウトと書いている、というのが肝心なところです。良い業者が見つかって、その場で契約書に判を押した瞬間に補助が消える、ということが起こります。

2つ目は、年度予算と先着です。福島市の特定空家等の枠は申請多数のため、新潟市は令和8年8月28日に予算上限に達したため、いずれもすでに受付を終了しています。北九州市は危険度の高いものから優先、札幌市は予定数に達した日の申請は抽選です。当社は、補助金は「あるかどうか」より「今年度まだ枠が残っているか」を先に確かめるものだと考えています。

  1. 家のある市区町村の空き家担当課に、制度の有無と対象を確認する。このとき今年度の受付期間と、枠が残っているかも聞く
  2. 市の事前確認・判定を受ける（札幌市は事前確認の依頼、北九州市は「判定依頼申出書」の提出。ここで対象と判定されて初めて交付申請ができます）
  3. 明細つきの見積を取る（申請書に工事費の内訳を添える制度が多いため）
  4. 交付申請
  5. 交付決定通知を受け取る
  6. 契約・着工
  7. 工事完了の報告、補助金の請求

危険度の判定は、市によっては交付申請より前に置かれています。札幌市は事前確認、北九州市は判定依頼申出書の提出が先で、対象と判定されてから交付申請です。名古屋市は市職員の現地調査で点数を評価します。この前段の受付は交付申請より早く締め切られます（表の受付欄）。

交付決定のあとにも締切があります。名古屋市は「補助金の交付決定があった日の属する年度の2月末日までに、工事が完了し、書類提出等のすべての手続きが完了する必要があります」、札幌市は「原則として、交付決定後3か月以内に工事完了の報告書を提出できる工事であること」。判定にも手続きにも数週間から1か月以上かかるので、「年内に更地にしたい」といった予定があるなら、逆算して早めに動いてください。

申請できる人にも条件があります。札幌市は法人等の申請ができず、申請者以外に建物の所有者がいる場合はその全員の同意が要ります。相続で共有名義になったままの空き家は、ここで止まります。

まとめ

  • 解体の補助は市区町村の制度。上限は30万〜150万円と幅があり、対象の条件もそれぞれ
  • 5市すべてで、交付決定より前の着工は対象外。札幌市と福島市は契約の時点でアウト
  • 年度予算・先着。5市のうち福島市の特定空家等の枠と新潟市（令和8年度分）はすでに受付終了
  • 順番は「自治体に確認 → 事前確認・判定 → 見積 → 申請 → 交付決定 → 契約・着工」
  • 判定を交付申請より前に置く市があり、その締切は申請の締切より早い。解体の予定日から逆算して動く

解体案内所は施工しません。届出・登記・補助金申請の代行や税務相談も行いません。解体する家のある地域で対応できる登録業者を手配し、明細つきの見積を最大3社まで並べます。業者からあなたへ営業電話をかけることはなく、連絡は最大3社の見積だけです。

よくある質問

見積を取ってから申請しても間に合いますか

見積は先で構いません。対象外になるのは、交付決定より前に「着工」した工事です。札幌市と福島市はさらに「契約」の時点でも対象外になると明記しているので、契約書に判を押す前に交付決定を受けてください。

どこの窓口に聞けばいいですか

家のある市区町村の空き家担当課です。住んでいる場所ではなく、建物のある自治体の制度が適用されます。聞くことは3つ。制度があるか、うちの家が対象か、今年度の枠がまだ残っているかです。

補助金が出る家と出ない家の違いは何ですか

老朽度や危険度の判定が入る制度が多く、名古屋市は市職員の現地調査による点数（75点以上・125点以上）、北九州市は基礎の破断や屋根の剥落などで判定します。北九州市は昭和56年5月以前の建築という条件もあります。まだ住める状態の家は対象外になることが多いです。
